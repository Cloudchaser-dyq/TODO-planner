# 有序 · 任务与课表规划器

videcoding的一个ddl-planner，希望对你有帮助~

黑白绿紫主题的离线规划工具：结合 DDL、个人权重和课表，生成任务排序与时间安排。

## 开始使用

双击 `有序.html`，添加自己的任务和固定安排。

1. 填写 DDL、预计总用时和评分。新任务默认进度 0%、目标 100%。
2. 在“固定安排”录入课程，支持每天、指定星期、单双周和起止周。
3. 查看实时排行，按阶段更新进度；参数变化后立即重算。

## 功能

- **表格与卡片**：直接编辑任务参数，自动保存；Enter 跳到同列下一行，Tab 跳到下一格。
- **优先级排序**：综合 DDL、重要性、愉悦性和工作量，支持负愉悦权重。
- **周期任务**：按天或周批量创建，设置间隔与次数，自动跳过重复项。
- **参考用时**：根据同名或相似任务提供估时建议，点击采用。
- **固定事件**：独立提醒；填写起止时刻后，任务排程避开该时段。每周课表按开始时间水平对齐。
- **每日记录**：保存部分推进、完成情况与实际用时，保留最近 14 天。

## 数据与备份

任务、进度、课表和记录保存在当前浏览器本地。个人计划与程序源码分开保存。

在“参数设置”导出或导入完整 JSON 备份。切换设备、浏览器或访问地址时，先导出再迁移。

“批量追加任务”支持合并去重，格式参考 `imports/example-tasks.json`；课表支持 CSV 导入导出。

## AI 助手

在“任务清单 → AI 修改任务”选择 DeepSeek 或 OpenAI，填写模型与自己的 API Key，用一句话添加任务、调整 DDL 或批量修改参数。

点击生成后，当前筛选事项和指令会发送给所选服务商。核对方案后应用，API Key 在当前页面使用，调用费用由服务商按账号计费。

遇到跨域限制时，运行 `node preview.cjs`，访问 <http://127.0.0.1:4173> 使用本机代理。切换到该地址前，先导出原计划，再导入备份。

## 北大教学网同步（Windows）

1. 安装 Node.js 22 或更新版本，双击 `启动教学网同步.cmd`，保持终端打开。
2. 在原来的 `有序.html` 中打开“任务清单 → 教学网同步”，粘贴终端显示的配对码。
3. 填写自己的账号和密码，按提示完成图形、短信或手机令牌验证，点击“读取 DDL”。
4. 核对预览并选择导入。疑似重复项会显示匹配依据，名称不同也可手动关联已有任务。关联后更新原任务的 DDL，保留进度、估时和评分。

同步读取[北京大学教学网](https://course.pku.edu.cn/webapps/login/)日历中近 30 天至未来 180 天、标记为作业的截止时间。无时区的时刻按北京时间显示，并在导入前提示核对。公告、附件中单独写出的日期需手动录入。

“记住登录”使用 Windows 当前用户加密，文件位于 `%LOCALAPPDATA%\有序\pku-sync\credentials.bin`。登录信息、验证码和配对码与任务备份、AI 请求及 Git 仓库分开；“清除本机登录”可删除已保存的登录信息。每次启动连接器生成新的配对码。

## 开发

```sh
node build.cjs     # 生成有序.html
node --test        # 运行测试
node preview.cjs   # 本地预览与 AI 代理
node pku-server.cjs # 本地教学网连接器
```

`dist/` 为模块化源码，`tests/` 覆盖排程、数据校验、表单保存、模拟 AI 与教学网接口，以及本机加密。
