# 有序 · 大学生任务与课表规划器
videcoding的一个ddl-planner，希望对你有帮助~
双击 `有序.html`，即可用浏览器打开完整网页。它是独立 HTML 文件，可以单独复制保存。无需安装依赖、无需填写 API Key，核心功能可离线运行。

## 开始使用

1. 首次打开是空白计划。添加自己的任务和固定安排，或手动导入自己的文件；需要体验示例时，可在参数偏好中明确选择“载入演示数据”。
2. 每件事填写整体 DDL 和完成 100% 的预计分钟数。可推进任务默认当前进度 0%、本轮目标 100%，也可以自行调整。例如总耗时 300 分钟，当前 20%，本轮目标 50%，这一轮安排约 90 分钟。
3. 在“我的课表”添加课程或其他固定安排。重复日期可选每天或指定星期，并填写开始结束时间、起止周和单双周。在“参数偏好”设置学期第一周日期。
4. 回到“实时排行榜”查看顺序和时间块。页面每分钟重算一次，修改进度、阶段目标、权重、课表后立即更新。

## 个人数据与批量导入

仓库只提供通用程序和虚构示例，不内置任何人的任务清单。任务、进度、课表、偏好和最近 14 天的每日记录保存在使用者当前浏览器的本地存储中，不会因使用本程序而自动上传到 GitHub。更新同一地址的程序会继续读取已有数据，不重置已经填写的进度与目标。

新建可推进任务默认当前进度 0%、本轮目标 100%，之后可以自行调整。未提供的预计时长、重要性和愉悦性保持留空；未估时的任务先按 DDL 暂定排序，不虚构时间块。固定事件使用参加状态和独立提醒，不进入可推进任务排名。

只确定日期时按 `YYYY-MM-DD` 记录，界面注明时刻待确认；用于估算截止风险时暂按该日结束处理。填写具体时刻后采用实际填写的时间。

“任务清单 → 批量追加任务”支持追加型 JSON。格式示例位于 `imports/example-tasks.json`，仅供手动选择导入，不会自动加载。这类导入会合并并去重，保留已有事项的进度、日期和其他资料；与“导入完整备份”的整份替换操作不同。导入标记随备份保存，重复导入不会复活已删除的事项。

## 在表格中集中编辑

“任务清单”初次使用默认显示编辑表格，可集中填写日期、可选时刻、整体预计分钟数、当前进度、本轮目标、重要性和愉悦性。离开输入框或切换下一格时自动保存；按 Enter 移动到同一列的下一行，按 Tab 依次移动到下一格。保存结果和输入错误会在表格上方提示。表格可以横向滚动，筛选菜单同时适用于表格和卡片视图；点击“卡片视图”可切回原来的展示方式。展示方式的选择会自动保存，下次打开继续沿用，也可以在“参数偏好 → 任务展示 → 默认展示方式”中选择；任务清单中的切换按钮会同步保存此设置。

在表格中提高任务进度，也会依照现有规则留下一条每日记录；只调整目标、日期、估时或评分不会新增进度记录。不填写实际用时不会推算工作时长，需要时可在记录或任务详情中补充。

固定事件可以编辑日期和可选起止时刻，其任务估时、百分比和评分列仅显示说明。点击“详情”可继续编辑完整资料或确认参加状态。

## 按周期创建任务

新建可推进任务时，勾选“按周期批量创建”，填写首次 DDL，再选择每天或每周、周期间隔和生成次数。次数包含首次，例如每 2 周、共 4 次，会从首次 DDL 起每隔两周生成一项，共四项。保存前可查看日期预览。

每次生成的都是独立任务，可以分别修改进度、估时和目标；已存在的同名同日期事项会跳过，已有资料不会被覆盖。编辑已有任务时不显示批量创建选项；需要继续添加后续任务时，可同名新建并填写下一次 DDL。

## 相似任务的参考用时

填写名称后，程序会查找名称相同或相似的任务，以已有估时的中位数提供参考。只有能够核对完整 0% → 100% 推进过程、且每段实际用时均已填写时，才将累计实际用时作为参考来源。每日记录仍只保留最近 14 天，不会根据缺失的记录推测完整用时。

参考用时会显示在任务表单及表格的预计用时栏附近。点击“采用参考用时”后才会填入；已有的预计用时不会因名称变化或页面刷新被自动覆盖，也不会改变任务进度与目标。

## 可选 AI 修改任务

“任务清单 → AI 修改任务”支持自带 API Key（BYOK），可选择 DeepSeek 或 OpenAI。DeepSeek 默认使用 `deepseek-flash`，OpenAI 默认使用 `gpt-6-luna`，模型名称可以修改。接口依据 [DeepSeek 官方文档](https://api-docs.deepseek.com/)和 [OpenAI Chat Completions 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)，请求费用由所选服务商按你的账号计费。

只有点击“生成修改方案”时才会发送本次指令和当前筛选的事项，最多 200 项，不发送每日记录、课表或其他筛选外的事项。先筛选任务，再填写类似“新增下周三的课程甲作业，把课程乙作业 DDL 改到周五”的指令。生成后会展示新增和修改的文字预览；确认“应用到任务”才会写入。应用前会对整个方案统一验证，全部合法后一次保存，有一项无效则不保存整批修改。

API Key 仅保留在当前页面，不写入本地任务数据、完整备份或 GitHub。可点击“清除密钥”，关闭页面后也需要重新填写。普通任务、课表、排序和每日记录功能仍可离线使用。

直接打开 HTML 时可以尝试连接所选官方接口。若遇到浏览器跨域（CORS）限制，运行 `node preview.cjs`，再访问 `http://127.0.0.1:4173`，通过本机代理请求。该代理仅转发到 DeepSeek、OpenAI 的官方接口，密钥只随本次请求传递，不写入文件或服务日志。这个本地 HTTP 地址与原 HTML 文件地址使用不同的浏览器存储：请先从原计划导出完整备份，再在新地址导入，继续使用原有资料。

当前没有使用真实 API Key 验证线上调用；接口链路的自动化测试使用模拟响应，不代表真实账号的可用额度或权限已经验证。

## 可推进任务与固定事件

添加或编辑事项时可以选择类型。作业、复习、项目属于可推进任务，使用重要性、DDL 和阶段百分比安排；考试、会议、预约等属于固定事件，只在固定时间发生，使用日期、可选的起止时刻、地点和参加状态。

事项类型由使用者明确选择；不会根据名称关键词或个人任务 ID 擅自改变类型。

固定事件会在首页单独提醒、在事项清单中显示，不会进入“现在先做什么”的任务排名，也不会被提前拆成百分比或专注块。只知道日期时显示具体时刻待确认，不假设考试时长；起止时刻完整后，会固定占用该时段并供任务避让，也不受学期周次限制。错过事件不会自动排成“补做考试”。

到发生时间后可以确认已参加，在最近 14 天的保留期内留下参加记录。确认参加不会把计划起止时刻当作实际投入时间；实际用时可以补记。备考或会前准备请另外创建可推进任务。

## 排序与时间安排

- 紧急程度由 DDL 自动推进，并结合整体剩余工作量、每日任务预算、课程空档估算。临近或已逾期的任务先按风险处理，再比较加权分。
- 重要性和愉悦性按 1–5 分记录。参数可以手动修改；愉悦性权重为负时，同等条件下不喜欢的事先排。默认使用负权重，“先苦后甜”预设可一键选择。
- 优先分按权重绝对值之和归一化，允许为负；负分仍会安排。它是辅助比较的估计值。
- 当前进度达到本轮目标后显示“本轮已达标”，整体任务在达到 100% 时才完成。继续推进时提高本轮目标即可。
- 阶段目标决定安排多少分钟，整体 DDL 风险仍按距离 100% 的全部剩余工作量计算。
- 时间安排会避开课程及课程前后缓冲，加入段间休息。“每天安排上限”默认关闭，只有明确开启后才采用你填写的上限；开启时，已记录的当日实际投入会扣减该日剩余额度。开始、结束时刻仅用于生成时间块，不代表整段时间都空闲。
- 预计时长和进度由你估计，可随时修正。截止前容量暂未替其他任务预留，因此多个任务同时临近截止时，应结合风险提醒人工调整。

## 每日记录与实际用时

“每日记录”按日期查看最近 14 天做过的事情。更新已有任务进度时，无论部分推进还是达到 100%，都会自动保存一条进度快照；只修改本轮目标不会新增一条工作记录。在编辑任务中提高进度也会自动记录。创建任务时填写的已有进度视为初始资料，不推测为今天完成。

可以填写实际开始、结束时刻（可跨午夜，单条不超过 24 小时），程序自动计算实际分钟数；也可只填写时长，或将时长留空。留空会显示“用时未填写”，不会当成零分钟的工作。实际用时与任务预计时长分别记录。

可以手动补记活动、关联任务、添加备注，并编辑或删除记录。历史记录保存当时的任务名称和进度快照；修改、删除历史记录只校正日志，不回退任务的当前进度，任务删除后其近期日志仍可查看。

日志采用滚动 14 个日历日：保留今天和之前 13 天，早于该日期的日志自动删除；不删除任务、课表、偏好或批次导入标记。打开页面、返回页面和页面运行期间会检查，关闭期间在下次打开时清理。导入备份也会执行保留期清理；不能补记未来或超过保留期的活动。日志随完整备份保存。

首页展示已记录实际用时、最近截止日期和待推进数量，不再将默认作息减去课程后的时长称作“可用空档”。

## 课表图片与文件

固定安排的“重复日期”可以选择“每天”。一条安排会每天重复，仍然遵守起始周、结束周和每周 / 仅单周 / 仅双周规则。每周课表将相同开始时刻的安排放在同一行，“每天”的安排在七天中保持水平对齐。

课表页面可选择图片对照录入。当前版本不自动识别截图；图片只在本次页面打开期间显示，不写入备份。实际课程录入后会参与自动排程。

支持课程 CSV 导入导出。表头：

```csv
课程,星期,开始,结束,地点,单双周,起始周,结束周
高等数学,星期一,08:00,09:40,A201,每周,1,16
```

星期也可使用数字 1–7，分别表示周一至周日。导入会追加课程；有错误时整份文件不导入。

## 保存与备份

任务、课表、参数与投入记录保存在当前浏览器的本地存储中。它们不会自动跨设备同步；换设备、换浏览器或从本地版切换到在线版前，请在“参数偏好”导出完整 JSON 备份，再到目标位置导入。清除浏览器数据也会影响本地记录。

网页代码和用户数据分开保存。正常更新同一地址的页面会继续读取旧数据。直接打开本地 HTML 文件时，浏览器对文件地址存储的行为没有统一保证，请保持文件名和位置不变，并在更新前导出备份。若已有数据无法解析、格式不兼容或读取异常，程序暂停写入并保留原存储，避免演示数据覆盖旧记录；只有明确确认导入替换或清空后才解除保护。

导入完整备份会先检查格式，再要求确认替换当前数据。演示数据、清空和删除操作均有确认提示。

## 文件与验证

- `有序.html`：可直接打开的单文件网页版，包含全部样式和逻辑。
- `dist/`：便于后续修改的模块化源文件，也可直接打开其中的 index.html。
- `build.cjs`：运行 `node build.cjs` 后，把模块化源文件打包为独立 HTML。
- `tests/`：自动排程、数据验证与表单保存链路测试。
- `preview.cjs`：可选本地预览服务器，运行 `node preview.cjs` 后访问 `http://127.0.0.1:4173`。

运行测试：`node --test tests/*.test.cjs`。交互链路测试使用轻量 DOM 模拟；当前环境没有可用浏览器自动化表面，尚未完成真实浏览器的视觉验收。
